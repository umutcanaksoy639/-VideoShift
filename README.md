# VideoShift

**Move fullscreen videos vertically without stretching or resizing.**

VideoShift is a free, open-source Tampermonkey userscript that lets you move videos up and down while watching in fullscreen mode.

Designed for people who want more control over video positioning, especially on 16:10 laptops, ultrawide monitors, and OLED displays.

 Features

- Move videos vertically using keyboard shortcuts
- Unlimited upward and downward movement
- Fine-tune positioning with 1 pixel precision
- Preserve the video's original aspect ratio
- No distracting pop-up controls on supported non-YouTube players
- Works with YouTube and aims to support other HTML5 video players
- Free and open source

 Installation

1. Install the Tampermonkey browser extension.
2. Download the `VideoShift.user.js` file from this repository.
3. Open the file with Tampermonkey and install the script.
4. Open a supported video website.
5. Enter fullscreen mode and use the keyboard shortcuts.

 Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Alt + ↑ | Move up 5 pixels |
| Alt + ↓ | Move down 5 pixels |
| Alt + Shift + ↑ | Move up 1 pixel |
| Alt + Shift + ↓ | Move down 1 pixel |
| Alt + PageUp | Move up 50 pixels |
| Alt + PageDown | Move down 50 pixels |
| Alt + B | Align to bottom |
| Alt + T | Align to top |
| Alt + R | Reset video position |

 Compatibility

VideoShift is designed for YouTube and other websites using HTML5 video players.

Compatibility may vary depending on the website, browser, fullscreen implementation, and video player. Not all streaming platforms have been tested.

 Why VideoShift?

Most video players automatically center the video in fullscreen mode.

VideoShift gives you control over where the video appears, without intentionally changing its dimensions.

Whether you're watching videos while lying down, using a 16:10 laptop, or experimenting with different screen layouts, VideoShift gives you more flexibility.

Moving video content does not guarantee prevention of OLED burn-in.
